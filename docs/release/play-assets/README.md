status bar). Re-run the script after replacing any raw capture. Every file is
PNG without an alpha channel. See `docs/release/PLAY_LISTING.md` for the
listing copy.

Play allows at most 8 phone screenshots; upload `01`–`08` in order (drop `08`
if you prefer seven). The names in the captures (Maya, Jonas, Leo, Priya, Sam)
are invented. The captures come from an emulator, not a physical phone
(see `PLAY_LISTING.md`), and the browser capture is headless Chrome at
432 × 864 CSS px, 2.5×.
